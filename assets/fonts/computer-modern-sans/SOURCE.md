# Computer Modern Sans Serif webfonts

CMU Sans Serif (Computer Modern Unicode). Regular/medium, bold, oblique and bold oblique webfont files from https://github.com/dreampulse/computer-modern-web-font/tree/master/font/Sans .

The font name used by the website is Computer Modern Sans Serif. Regular is mapped to CSS weight 400 (normalfont), bold to 700 (bfseries). The embedded CMU Sans Serif regular font identifies its design as Medium; it is the standard normal face provided by the source stylesheet. Fredoka is retained only for the SyncTime wordmark. See OFL.txt for the font license.
