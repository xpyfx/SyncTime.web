01 / 徵旅伴

找到剛好同行的人。

依目的地、日期、預算和同行條件探索旅程，查看完整資訊，找到適合加入的計畫。

  • 目的地篩選
  • 旅程條件
  • 尋找旅伴
01 / 行程規劃

把想去的地方，排成旅程。

在旅程詳情安排每天的活動與景點，讓同行的人一眼看懂旅行節奏。

  • 每日行程
  • 景點安排
  • 共同規劃
02 / 旅吧

異地的日常，也值得被看見。

在旅吧分享旅途見聞，從熱門、推薦與好友動態發現新的旅行故事。

  • 圖文分享
  • 興趣標籤
  • 旅行見聞
03 / 聊天室

從一句你好，走到同一條路上。

加入旅程群組後討論集合時間、分享地點，還能發起投票、抽籤和行程卡。

  • 群組聊天
  • 地點分享
  • 旅程投票
03 / 導出行程

一張行程表，帶著大家出發。

把群組共同整理的每日行程製作成行程卡，並匯出 PDF 保存或分享。

  • 行程卡
  • 每日安排
  • 匯出 PDF
03 / 記帳功能

旅費分得清楚，玩得更輕鬆。

在聊天室記錄共同支出、代付者與分攤金額，旅行結束時查看結算。

  • 共同記帳
  • 旅費分攤
  • 結算明細
04 / 旅遊軌跡紀錄

去過的地方，最後都成了故事。

記錄旅行的國家、城市、日期與同行的人，在軌跡列表中回看每段旅程。

  • 新增足跡
  • 年度整理
  • 旅行紀錄
04 / 分享個人軌跡

讓走過的路，成為你的故事。

由自己決定是否公開旅遊軌跡，也能將旅行紀錄製作成圖片或檔案分享。

  • 公開設定
  • 軌跡分享
  • 旅行回憶
04 / 軌跡數據分析

用數字，回望走過的世界。

切換軌跡分析，依年份查看旅行足跡與統計，回顧探索過的地方。

  • 年度統計
  • 國家城市
  • 足跡分析
05 / 個人資訊統整

每段旅程，都拼成獨一無二的你。

在個人頁集中展示旅行足跡、標籤、國家印章、旅伴評價與自我介紹。

  • 旅行護照
  • 個人檔案
  • 旅伴印象
05 / 專屬標籤

讓旅伴看見你的旅行風格。

挑選最多六個個人標籤，從興趣、習慣到旅行偏好，介紹自己的步調。

  • 個人興趣
  • 旅行偏好
  • 最多六個
05 / 旅遊印章圖鑑收集

每抵達一個國家，就多一枚紀念。

在各國印章圖鑑回看已探索的國家，收藏旅程留下的紀念印章。

  • 國家印章
  • 圖鑑收集
  • 旅遊紀念
05 / 個人評價

一起走過的旅伴，留下真實印象。

旅程結束後可評價同行旅伴，在個人頁查看收到與給出的評價。

  • 旅伴評價
  • 旅行心得
  • 個人信任
05 / 自我介紹

出發之前，先認識彼此。

寫下你的旅行喜好、步調與期待，讓未來的旅伴更了解你。

  • 個人故事
  • 旅行喜好
  • 認識旅伴
